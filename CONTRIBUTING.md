Thank you for your interest in contributing!

Guidelines
- Fork the repository and open a Pull Request against `main`.
- Keep changes small and focused.
- Add tests for new behavior where possible.
- Ensure `go vet` passes and code is `gofmt` formatted.

Code style
- Use `go fmt` / `gofmt` for Go files.
- Keep docs and README up to date.

Reporting issues
- Open an issue with a minimal reproduction and steps to reproduce.
